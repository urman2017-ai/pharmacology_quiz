# Фармакология — тесты к коллоквиуму

Интерактивное веб-приложение для подготовки ко 2-му коллоквиуму по фармакологии.

**Темы:**
- Местные анестетики (лидокаин, новокаин, бупивакаин и др.)
- Адреномиметики и симпатомиметики
- Адреноблокаторы и симпатолитики
- Классификация и сопоставление препаратов

Основано на учебнике **Харкевича Д.А.** и материалах кафедры общей и клинической фармакологии.

## Как пользоваться

1. Открой [index.html](index.html) в браузере (или GitHub Pages).
2. Выбери тему или «Все темы».
3. Отвечай на вопросы — сразу показывается правильный ответ и краткое объяснение.
4. В конце — результат в процентах.

## Запуск локально

Просто открой `index.html` двойным кликом или через любой статический сервер.
