# Фармакология — тесты (iPhone)

Веб-приложение для подготовки ко 2-му коллоквиуму по фармакологии.

## На iPhone

1. Открой в **Safari**: https://urman2017-ai.github.io/pharmacology_quiz/
2. Поделиться → **На экран «Домой»** → Добавить

Работает как приложение, офлайн после первой загрузки.

## Темы

Местные анестетики, адреномиметики, адреноблокаторы, классификация (Харкевич).
